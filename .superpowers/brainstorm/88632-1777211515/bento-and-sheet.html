Detail sheet — per-occurrence controls

Currently the user can disable individual occurrences (each row has its own checkbox). Should we keep that, or drop to a card-level-only toggle?

A

Keep per-occurrence checkboxes

Detail sheet rows: ▶ preview · excerpt · 0:20 · ☐ checkbox. User can fine-tune which "you know" instances to cut. More power, more complexity.

B

Detail sheet is read-only previews

Detail sheet rows: ▶ preview · excerpt · 0:20 (no checkbox). Only the bento card's group toggle controls cuts. Simpler mental model — "I disable a word, I disable all its occurrences." Match the Premium Studio aesthetic better.

C

Hybrid — group toggle + "Edit instances" link

Detail sheet shows previews read-only by default. A small "Edit individual instances" link reveals checkboxes. Hides complexity by default but keeps power available.
